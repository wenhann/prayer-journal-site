支援與常見問題

聯絡我們

有問題、建議或發現錯誤，請到 GitHub Issues 留言（需要 GitHub 帳號），也可以在 App Store 頁面留下評論。

怎麼記錄「已禱告」？

在清單上把代禱向右滑，或按「今日」的「開始禱告」一張一張禱告（卡片往右滑表示已禱告）。主畫面小工具也可以直接按 ✓。

「暫停代禱」是什麼？

向左滑可以暫停：暫停的代禱不會出現在「今日」和提醒，資料都保留，隨時可以恢復。神已經回應或不需要再代禱時，請按「回應」記下結果。

iCloud 同步沒有作用？

  • 確認 iPhone 已登入 iCloud，並在「設定 → Apple 帳號 → iCloud → 使用 iCloud 的 App」打開「代禱」。
  • App 的「設定 → 同步與備份」會顯示目前狀態；第一次同步可能需要幾分鐘。

怎麼從網頁版搬過來，或備份？

在網頁版「設定 → 備份」匯出 JSON 檔，然後在 App 的「設定 → 還原備份」選這個檔案，可以選擇合併或取代。App 匯出的備份也能在網頁版還原。

沒有收到提醒？

到 App 的「設定 → 提醒」打開每日提醒，並確認 iOS「設定 → 通知 → 代禱」允許通知。今天的代禱都禱告完時，當天就不會再提醒。

怎麼分享到 LINE 或印出來？

單一代禱向左滑按「分享」；多個代禱到「代禱」頁右上角的分享按鈕，選好範圍後按「分享文字」，或在「PDF」選單預覽、列印清單或禱告小卡。

忘了 Face ID 鎖定怎麼辦？

解鎖可以改用裝置密碼。要關掉鎖定，到 App 的「設定 → 隱私」。

Support (English)

For questions, suggestions or bug reports, please open an issue at GitHub Issues. Swipe right on a prayer to record that you prayed; swipe left to pause or share it. iCloud sync requires iCloud to be enabled for the app in iOS Settings. Backups can be exported and imported as JSON in the app's Settings and are compatible with the web version.
